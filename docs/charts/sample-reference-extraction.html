  3. deluge_sdk.py_get_preset_name(element: etree._Element, xml_type: str, xml_path: Path)str
    1. If element.tag == "audioClip"
      1. ExitReturn trackName or "unknown"
    2. Otherwise, if xml_type != "song"
      1. ExitReturn xml_path.stem
    3. For a song, walk the element and its ancestors
      1. If the parent tag is instruments
        1. ExitReturn current.presetName if nonempty, otherwise "unknown"
    Return"unknown" if no owning instrument is found
