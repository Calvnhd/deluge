    1. InputKit InstrumentClipGroup, normally checked before selection unless --include-sidechain
    2. StateRequire soundSources with at least one sound; use the lowest-section clip
    3. If exactly one sound has integer sideChainSend >= int(2147483647 * 0.99)
      1. ExitReturn (True, single-sound reason); malformed send is treated as zero on this path
    4. StateFor the multi-sound route require exactly one noteRow with noteDataWithLift
    5. StateRequire a valid drumIndex selecting an existing sound, and its valid integer sideChainSend at or above the threshold; otherwise return (False, "")
    6. If kitParams volume is a recognized hex string

      2. If volume <= -1073741824
        1. ExitReturn (True, low-kit-volume reason)
