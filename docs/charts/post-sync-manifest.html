  1. syncing.py build_post_sync_manifest(plan: SyncPlan, src_scan: ScanResult, dest: Path, old_files: dict[str, FileRecord], source_is_sd: bool, file_filter: str = "both") dict[str, FileRecord]

    Called after successful file operations by Sync from SD and the reverse SD sync; uses the earlier source scan, not a fresh scan

    1. For each (_src, dst) in plan.files_to_copy
      1. scanning.pynormalise_key(dst.relative_to(dest))str
        ReturnNormalized copied-file key, added to copied_keys
    2. StateInitialize updated_manifest={} and keys_to_hash=[]
    3. For each (key, src_entry) in src_scan.files
      1. If key exists in old_files and is not in copied_keys
        1. StateReuse old_files[key] directly, including any in-memory metadata refresh made during planning
      2. Otherwise, the file was copied or has no previous manifest record
        1. Statedst_path=dest/src_entry.rel_path
        2. pathlib.pydst_path.stat()
          ReturnCurrent destination size and raw mtime
        3. scanning.pynormalise_mtime(dst_stat.st_mtime)float
          ReturnDestination mtime truncated to a 2-second boundary
        4. If source_is_sd
          1. StateRecord SD size/mtime from src_entry and local size/mtime from destination stat
        5. Otherwise, source is local and destination is SD
          1. StateRecord local size/mtime from src_entry and SD size/mtime from destination stat
        6. StateQueue (key, dst_path) in keys_to_hash
    4. If keys_to_hash is not empty
      1. For each (key, path) in keys_to_hash, after all metadata records are built
        1. OutputPrint hashing progress
        2. deluge_sdk.pyhash_file(path)str

          Open the destination file in binary mode, read 64 KiB chunks, and compute SHA256

          ReturnHex digest for the copied/newly recorded file
        3. StateAssign the returned digest to updated_manifest[key]["hash"]
    5. If file_filter != "both"
      1. StateLook up scanned_exts=FILTER_MAP[file_filter]
      2. For each (key, old_entry) in old_files
        1. If key is absent from updated_manifest and its extension is not in scanned_exts
          1. StatePreserve old_entry so a filtered sync does not discard records for excluded file types
    Returnupdated_manifest; records absent from the source are dropped for the selected file types
    ExceptionStat and hashing OSError propagate to the caller; this function does not persist JSON

sync_from_sd.py uses source_is_sd=True; sync_to_sd.py uses False; each separately calls write_manifest after this function returns

fix_references.py shares manifest read/write helpers but does not call this rebuilding flow

Reused records are not copied, restatted, or rehashed; even an unchanged source file is hashed if it lacks an old manifest record
