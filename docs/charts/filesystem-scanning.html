Execution flow

Filtered filesystem scanning

Walk a directory tree, collect XML/WAV file metadata, and return entries keyed by normalized relative paths

Script Shared Deluge library Python standard library
Show depth
  1. scanning.py scan_tree(root: Path, *, label: str = "source", file_filter: FileFilter = "both") ScanResult

    Sync planning invokes this once per tree; other scripts also use this metadata-only scanner

    1. InputFILTER_MAP selects .xml, .wav, or both; label affects progress messages only
    2. scanning.pyScanResult()
      Resultresult with an empty files dict
    3. Statefile_count=0; print the initial scanning message
    4. os.pyos.walk(root)

      Create a top-down traversal iterator; iteration below drives directory enumeration

      ReturnIterator of (dirpath, dirnames, filenames); no custom onerror callback or followlinks option
    5. For each directory tuple yielded by the walk iterator
      1. Statecurrent_dir=Path(dirpath); prune child names matching .trash case-insensitively by modifying dirnames in place
      2. For each fname in filenames, without explicit sorting
        1. Statefile_path=current_dir/fname; compare file_path.suffix.lower() with the selected extensions
        2. If the extension is not selected
          1. StateContinue with the next filename without stat capture
        3. Otherwise, attempt metadata capture
          1. pathlib.pyfile_path.stat()
            ReturnFile size and raw mtime on success
          2. If stat raises OSError
            1. OutputWarn with the relative path and error; skip the file and continue
          3. If stat succeeds
            1. Staterel=file_path.relative_to(root)
            2. scanning.pynormalise_key(rel)str
              Returnstr(PurePosixPath(rel)).lower() used as the lookup key
            3. scanning.pynormalise_mtime(st.st_mtime)float
              Return2.0 * (raw_mtime // 2.0), truncating to FAT32's 2-second resolution
            4. scanning.pyFileEntry(rel_path=rel, size=st.st_size, mtime=normalise_mtime(st.st_mtime))

              The preceding normalise_mtime call is argument evaluation for this construction, not a second invocation

              ResultFrozen entry preserving the relative Path, file size, and normalized mtime
            5. StateAssign result.files[key]=entry; a repeated normalized key replaces the earlier entry
            6. OutputIncrement file_count and print progress for the captured file
    6. OutputPrint final file_count, which counts captures rather than unique dict keys
    Returnresult containing the captured FileEntry records; no file hashing or content writes

Direct script callers include create_backup.py, sample_overview.py, and fix_references.py; deluge_sdk.py also calls this scanner

Per-file stat failures warn and skip; os.walk uses its default handling of directory-enumeration errors, so a returned scan is not a guarantee that every file was readable
