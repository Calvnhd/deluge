  1. analysis.pybuild_usage_index(refs: list[SampleRef], sample_scan: ScanResult)UsageIndex
    1. InputSampleRef list and ScanResult supplied by sample_overview main; scan keys are relative to SAMPLES, XML ref paths normally start with SAMPLES/
    2. First, for every scanned file
      1. scanning.pyprint_path(file_entry.rel_path)str

        Canonical implementation

        ReturnCase-preserving display path
      2. StateCreate SampleUsage(path, size, refs=[], on_disk=True) under the scan key
    3. Then, for every reference occurrence
      1. analysis.py_ref_key(ref.path)str

        Canonical implementation

        ReturnComparable sample key
      2. If key is already in entries
        1. StateAppend this occurrence to the existing refs list
      3. Otherwise
        1. StateRemove a case-insensitive SAMPLES/ display prefix if present; create SampleUsage(size=None, refs=[ref], on_disk=False)
    4. StateConstruct UsageIndex(entries=entries)
    ReturnUsageIndex covering on-disk files and referenced-but-missing samples; no occurrence deduplication
  2. analysis.py_ref_key(ref_path: str)str
