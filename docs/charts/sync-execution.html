  1. syncing.py execute_plan(plan: SyncPlan, *, dest: Path, delete_mode: str = "trash") SyncResult

    Sync from SD takes the default trash branch; the other sync scripts pass delete_mode="delete"

    1. Statecopied=0; total_copy=len(plan.files_to_copy)
    2. Try each (src, dst) in plan.files_to_copy, in plan order
      1. OutputPrint copy progress
      2. pathlib.pydst.parent.mkdir(parents=True, exist_ok=True)
        OutputEnsure the destination parent directory exists
      3. shutil.pyshutil.copy2(src, dst)
        OutputCopy file content and attempt to preserve metadata; an existing destination can be overwritten
      4. StateIncrement copied only after copy2 returns
    3. If mkdir or copying raises OSError
      1. syncing.pySyncError(str(exc), file=str(src), copied=copied, unchanged=plan.files_unchanged, remaining=total_copy - copied - 1)
        ResultError with source path, completed copies, trashed=0, and remaining copies excluding the failed item
      2. RaiseRaise the constructed SyncError from exc; skip all removals and the normal return
    4. StateAfter all copies succeed: trashed=0; trash_count=len(plan.files_to_delete)
    5. If trash_count > 0 and delete_mode == "trash"
      1. OutputPrint the number of files to trash
      2. datetimedatetime.now().strftime("%Y%m%d_%H%M%S")str
        ReturnTimestamp used once to form trash_base=dest/".trash"/timestamp
      3. Try each path in plan.files_to_delete
        1. Staterel=path.relative_to(dest); trash_dest=trash_base/rel
        2. pathlib.pytrash_dest.parent.mkdir(parents=True, exist_ok=True)
          OutputPreserve relative directory layout under the trash timestamp
        3. shutil.pyshutil.move(str(path), str(trash_dest))
          OutputMove the extra destination file into trash
        4. StateIncrement trashed after the move returns
      4. If a trash operation raises OSError
        1. syncing.pySyncError(str(exc), file=str(path), copied=copied, trashed=trashed, unchanged=plan.files_unchanged, remaining=trash_count - trashed - 1)
          ResultError with completed work and remaining removals excluding the failed item
        2. RaiseRaise SyncError from exc; no rollback or normal result
    6. Otherwise, if trash_count > 0 and delete_mode == "delete"
      1. Try each path in plan.files_to_delete
        1. OutputPrint deletion progress
        2. pathlib.pypath.unlink()
          OutputPermanently delete the file
        3. StateIncrement trashed; the same counter records permanent deletions
        4. Starting at path.parent, while parent != dest
          1. pathlib.pyparent.rmdir()
            OutputRemove the parent only if empty
            ExceptionAny OSError breaks this ancestor loop without failing the sync
          2. StateAfter successful rmdir, advance parent=parent.parent
      2. If deletion raises OSError outside the handled ancestor cleanup
        1. syncing.pySyncError(str(exc), file=str(path), copied=copied, trashed=trashed, unchanged=plan.files_unchanged, remaining=trash_count - trashed - 1)
          ResultError with completed copies/deletions and remaining removals excluding the failed item
        2. RaiseRaise SyncError from exc; no rollback or normal result
    7. Otherwise, no removals or an unrecognized delete_mode
      1. StateNo removal branch runs; delete_mode is not validated by this function
    8. syncing.pySyncResult(copied=copied, trashed=trashed, unchanged=plan.files_unchanged)
      ResultCompleted operation counts
    ReturnConstructed SyncResult to the caller for logging and subsequent work

Existing callers: sync_from_sd.py trashes extras; sync_to_sd.py and sync_samples_to_cloud.py permanently delete extras

Logging, confirmation, manifest updates, and final clean_empty_dirs calls belong to callers; this function performs no rollback

SyncError.remaining counts later items in the failing phase, not all outstanding plan operations
