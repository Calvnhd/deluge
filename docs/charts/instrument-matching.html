Discover and match song instruments

Read embedded instruments and session clips, then match preset-name/folder keys and classify unmatched instruments

  1. extraction.pydiscover_instruments(song_tree: etree._Element)list[InstrumentInfo]
    1. InputParsed song tree supplied by the extraction or benchmark preparation loop
    2. If instruments is missing
      1. ExitReturn []
    3. For each instruments child
      1. StateAccept sound as synth and kit as kit; ignore MIDI and audioTrack
      2. StateConstruct InstrumentInfo retaining the original element, presetName and presetFolder
    ReturnInstrumentInfo list in source order
  2. extraction.pydiscover_clips(song_tree: etree._Element)list[ClipInfo]
    1. If sessionClips is missing
      1. ExitReturn []
    2. For each sessionClips child
      1. StateAccept instrumentClip only; read instrumentPresetName and instrumentPresetFolder
      2. If section is absent
        1. OutputWarn and select section=0
      3. Otherwise
        1. StateConvert section with int; invalid numeric values propagate ValueError
      4. StateConstruct ClipInfo retaining the source element
    ReturnSession ClipInfo list; arrangementOnlyClips are not collected
  3. extraction.pymatch_instruments_to_clips(instruments: list[InstrumentInfo], clips: list[ClipInfo], song_tree: etree._Element | None=None)tuple[list[InstrumentClipGroup], list[str]]
    1. InputInstrumentInfo list, ClipInfo list and optional source song tree
    2. StateIndex clips by (preset_name, preset_folder)
    3. For each instrument in source order
      1. StateLook up matching clips by the same name/folder pair
      2. If no session clips match
        1. StateIf song_tree is available, search arrangementOnlyClips for the same key
        2. OutputAdd an arrangement-only or orphan warning and skip the instrument
      3. Otherwise
        1. For each matching clip
          1. If the section was already retained
            1. OutputAdd duplicate-section warning and keep the first clip
          2. Otherwise
            1. StateStore clip under its section
        2. StateConstruct InstrumentClipGroup and append its warnings to the flat warning list
    Return(groups, warnings); input XML elements are not modified
