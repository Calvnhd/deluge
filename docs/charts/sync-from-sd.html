      Copy first, then trash destination-only files using the default delete_mode="trash"; expand plan execution

      Returnresult with copied, trashed, and unchanged counts on success

    19. If execute_plan raises SyncError
      1. timetime.monotonic()float
        ReturnFailure time; subtract start_time to compute elapsed
      2. syncing.pySyncResult(copied=exc.copied, trashed=exc.trashed, unchanged=exc.unchanged)

      3. syncing.pyappend_sync_log(error_result, direction="from-sd", elapsed_seconds=elapsed, error=str(exc))None
        OutputAppend FAILED, timestamp, direction, counters, elapsed time, and error to scripts/data/logs/sync.log
      4. ExitPrint failure details and raise SystemExit(1); manifest rebuilding, success reporting, and cleanup are skipped
    20. If execute_plan returns successfully
      1. timetime.monotonic()float
        ReturnCompletion time; subtract start_time to compute elapsed
      2. syncing.pyappend_sync_log(result, direction="from-sd", elapsed_seconds=elapsed)None
        OutputAppend SUCCESS and file-operation counters to scripts/data/logs/sync.log before any manifest update
      3. Try to rebuild and persist the manifest
        1. syncing.pybuild_post_sync_manifest(plan, src_scan, deluge_root, manifest_files, source_is_sd=True, file_filter=file_filter)dict[str, FileRecord]

          Reuse unchanged records, capture destination metadata, and hash copied/new files; expand manifest rebuilding

          Returnupdated_manifest, preserving records for excluded file types
        2. syncing.pywrite_manifest(SYNC_MANIFEST_PATH, files=updated_manifest)None

          Create the parent directory and serialize version 2, a current timestamp, and records with explicit hash fields

          1. tempfile.pytempfile.NamedTemporaryFile(mode="w", encoding="utf-8", dir=str(path.parent), suffix=".tmp", delete=False)
            ResultTemporary text file in the manifest directory, entered as fd
          2. OutputWrite and flush JSON through fd, then close the file on leaving its context
          3. pathlib.pytmp_path.replace(path)
            OutputAtomically replace the manifest with the completed temporary file
          ExceptionWrite/flush or replace failures attempt temporary-file removal and re-raise
      4. If rebuilding or writing raises OSError
        1. OutputPrint a warning that file sync succeeded but manifest updating failed; continue
      5. OutputPrint "Sync complete" with copied and trashed counts
      6. syncing.pyclean_empty_dirs(deluge_root)int

        Walk bottom-up, preserve the root and its immediate children, and attempt rmdir for directories deemed empty

        Filter .trash names from child checks; bottom-up traversal does not prune already-visited .trash subtrees

        OutputReport removals and warn on caught rmdir failures
        ReturnNumber of directories removed, ignored by main
    ReturnNone after a successful sync or a documented early return

Source-derived alternatives, not a runtime recording; dry runs still scan and may hash files

Only execute_plan SyncError and manifest-update OSError have dedicated handlers; other failures, including log I/O errors, can propagate

Standard-library calls are shown at API level; Python 3.12 documentation links do not assert the executing interpreter version
