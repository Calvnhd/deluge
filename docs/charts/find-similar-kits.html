  2. find_similar_kits.pyfind_matches(kits: list[KitProfile], *, max_differences: int=3, reference: Path | None=None)list[KitMatch]
    1. ExceptionReject max_differences < 0 with ValueError
    2. StateResolve optional reference; sort kits by path and group them by candidate_key
    3. For every pair from combinations(group, 2)
      1. If a reference was supplied and neither side is it
        1. StateSkip pair
      2. For each sorted numeric key on the left profile
        1. StateCompare raw field strings; append ParameterDifference when unequal
        2. If the changed-field count exceeds max_differences
          1. StateBreak early; do not retain this pair
      3. StateIf within threshold, construct KitMatch with its tuple of differences
    4. StateSort matches by changed-field count, then left path and right path
    Returnlist[KitMatch]; exact raw numeric-string differences, not proportional or audio comparisons
