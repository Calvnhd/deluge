  1. fix_references.py_compute_migration_map(manifest: FilesDict, deluge_root: Path)MigrationResult
    1. InputFilesDict from the last sync and the current Deluge root; called by the fixer and again after confirmed duplicate deletion
    2. StateGroup every manifest record having a non-None hash under that digest; this loop does not filter manifest paths to WAVs
    3. If manifest is empty
      1. OutputWarn that move detection is unavailable
    4. If SAMPLES is not a directory
      1. OutputWarn about the missing directory
      2. ExitReturn an empty MigrationResult
    5. scanning.pyscan_tree(samples_dir, label="SAMPLES", file_filter="wav")ScanResult

      Canonical implementation

      ReturnCurrent WAV metadata
    6. For each scanned WAV entry
      1. StateRetain a case-preserving SAMPLES/... POSIX path and absolute file path
      2. scanning.pynormalise_key(library_path)str

        Canonical implementation

        Returnmanifest_key
      3. If a manifest record has a non-None hash, positive local mtime and exactly matching size/mtime
        1. StateTrust the cached hash; append the library path under it; continue
      4. StateOtherwise queue the library path and absolute path for hashing
    7. For each queued file after metadata checks
      1. OutputPrint hash progress
      2. deluge_sdk.pyhash_file(abs_library_path)str

        Canonical implementation

        ReturnCurrent digest
      3. StateGroup library_path under the digest
    8. For each digest in the union of manifest and current-library indexes
      1. Exactly one manifest path and one library path
        1. scanning.pynormalise_key(library_paths[0])str

          Canonical implementation

          ReturnComparable current key
        2. StateIf old key differs, record moved[old]=current case-preserving path; otherwise omit unchanged content
      2. Else manifest paths exist but no library paths
        1. StateRecord deleted[digest]
      3. Else library paths exist but no manifest paths
        1. StateRecord added[digest]
      4. Else multiple manifest paths and at least one library path
        1. StateNormalize current paths; record manifest paths no longer present as stale[digest]
      5. Independently, if more than one library path shares the digest
        1. StateRecord lib_duplicates[digest]
    9. ExceptionHashing errors propagate; permissive scan omissions can affect the inferred classifications
    ReturnMigrationResult(moved, deleted, added, stale, lib_duplicates, library_hashes)
  2. fix_references.py_handle_duplicates(migration_map: MigrationResult, manifest: FilesDict, deluge_root: Path)MigrationResult
    1. InputMigrationResult with digest groups, original manifest, and Deluge root from fixer main
    2. For each duplicate group in current library order
      1. StateKeep paths[0]; schedule every later path for permanent deletion
    3. If no deletion pairs exist
      1. ExitReturn the original migration_map
    4. OutputPreview each keeper and the files to delete
    5. cli_utils.pyconfirm_apply(f"\nDelete {len(to_delete)} file(s)?")bool

      Canonical implementation

      ReturnDeletion consent
    6. If False
      1. OutputNo duplicates removed
      2. ExitReturn the original migration_map
    7. For each scheduled duplicate
      1. pathlibabs_path.unlink()
        ReturnDuplicate removed
      2. StateIncrement deleted_count after success
      3. If unlink raises OSError
        1. OutputWarn about that path and continue; no rollback
    8. OutputPrint count removed
