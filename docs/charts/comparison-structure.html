  2. extraction.py_check_modknobs_structure(parent_a: etree._Element, parent_b: etree._Element, prefix: str='')list[str]
    1. InputTwo sound parents and optional prefix from synth or per-kit-sound comparison
    2. StateRead modKnobs children on each side as positional lists
    3. If both lists are empty
      1. ExitReturn []
    4. For each position up to the longer list length
      1. StateTreat missing knobs as absent; compare controlsParam and patchAmountFromSource
      2. StateAppend positional changed/added/removed descriptions with the optional prefix
    ReturnHard-difference descriptions
  3. extraction.py_check_kit_structure_hard(preset_a: etree._Element, preset_b: etree._Element, hard_attrs: dict[str, set[str]], config: ComparisonConfig)list[str]
    1. StateRead soundSources child lists from both kits
    2. If configured _count differs
      1. ExitReturn a sound-count hard difference before per-sound checks
    3. If configured ordered _names lists differ
      1. ExitReturn a sound-name hard difference before per-sound checks
    4. For zipped sounds with strict=True
      1. StateCompare configured sound-root and nested child hard attributes, skipping sentinel/ignored attributes
    5. For each paired sound
      1. extraction.py_check_patchcable_structure(sdp_a, sdp_b)list[str]

        Canonical implementation

        ReturnRouting differences, prefixed with the sound name
    6. For each paired sound again
      1. extraction.py_check_modknobs_structure(sa, sb, prefix=f"sound[{name}]")list[str]

        Canonical implementation

        ReturnPrefixed knob differences
    7. ExceptionA custom config that bypasses count guards can expose strict-zip ValueError for unequal sound lists
    ReturnAll accumulated per-kit structural hard differences
  4. extraction.py_build_patchcable_dict(default_params: etree._Element | None)dict[tuple[str, str], str]
    1. If default_params or its patchCables child is missing
      1. ExitReturn {}
    2. For each patchCable child
      1. StateIndex amount string by (source, destination), defaulting missing attributes to ""; later duplicate routes replace earlier values
    Returndict[(source, destination), amount]
  5. extraction.py_build_patchcable_element_dict(default_params: etree._Element | None)dict[tuple[str, str], etree._Element]
    1. If default_params or its patchCables child is missing
      1. ExitReturn {}
    2. For each patchCable child
      1. StateIndex the element by (source, destination); later duplicate routes replace earlier elements
    Returndict[(source, destination), cable element]
